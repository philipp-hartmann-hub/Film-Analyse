# Outside the box

Letterboxd-Statistik über den öffentlichen **RSS-Feed** (funktioniert auf Vercel ohne Cloudflare-403).

## Nutzung

```bash
npm install
npm run dev
```

Username oder `https://letterboxd.com/deinname/` eingeben.

## Grenzen

- Bis zu **100** Tagebuch-Einträge aus dem RSS (Letterboxd-Limit)
- Keine Genre-/Regie-Anreicherung (Filmseiten werden auf Vercel geblockt)
